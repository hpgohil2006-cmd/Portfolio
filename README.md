The application follows a modular JavaScript structure:

├── Product Module
│      └── products.js
│
├── Cart Module
│      └── cart.js
│
├── Application Module
│      └── app.js
│
└── UI
       ├── HTML
       └── CSS

This separation makes the application easier to understand, maintain and extend.
